# 排班小幫手｜課堂演練

一個用來練習 Excel 匯入、簡易排班與 Excel 匯出的繁體中文網頁。開啟後可以直接使用內建的 8 位模擬同仁，或下載範例需求表、修改後重新匯入。

## 手動啟動

需要 Git 和 Python 3；無需安裝 npm 套件或執行建置。

```bash
git clone https://github.com/AndyJuang/shift-planner-demo.git
cd shift-planner-demo
python3 -m http.server 8000 --directory dist
```

Windows 可將最後一行改為：

```powershell
py -m http.server 8000 --directory dist
```

在瀏覽器開啟 <http://localhost:8000>。使用完畢後，在執行伺服器的終端機按 `Ctrl+C` 停止。如果 8000 埠已被占用，將指令中的 `8000` 換成其他可用埠，網址也換成同一個埠號。

也可以直接開啟 `dist/index.html`；使用本機伺服器則更方便在不同瀏覽器測試。打包分享時請保留整個 `dist` 資料夾，因為 HTML、CSS、JavaScript 和 Excel 處理程式會互相引用。

## 操作方式

1. 點選「使用模擬資料」，或下載範例需求表並按格式填寫後上傳。
2. 選擇排班月份，設定每日早班、晚班人數與最多連續上班天數。
3. 點選「產生下個月班表」，檢查未排滿班次與未滿足的班別偏好。
4. 點選「匯出 Excel」，下載班表及排班說明。

範例 Excel 的第一個工作表須有「姓名」「日期」「需求」三欄；日期使用 `YYYY-MM-DD` 或 Excel 日期格式，需求填 `休假`、`早班` 或 `晚班`。每位同仁可用一列姓名、日期與需求空白的資料加入名單；同一位同仁同一天只能填一筆需求。需求日期不在選定月份時會被略過並提示。

## 示範規則與限制

- 指定休假與最多連續上班天數是排班條件；早晚班偏好盡量滿足。
- 系統以簡易方法安排，嘗試兼顧班次數與班別；未排滿不代表問題一定無解。
- 這是教學範例，**不會自動判定勞動法規、工時、跨月連續上班、輪班休息間隔或所有實務需求**。班表須由管理員複核後使用。
- Excel 在瀏覽器內處理，這個專案的程式不會將檔案上傳到伺服器；網頁字型使用 Google Fonts，離線時會改用系統字型。
- 專案內的兩個 Excel 檔為虛構的 2026 年 12 月教學範例；實際演練月份可在網頁中變更，並重新下載對應月份的範例表。

## 檔案結構

- `dist/index.html`：網頁入口。
- `dist/style.css`、`dist/app.js`：介面、匯入匯出與排班邏輯。
- `dist/xlsx.full.min.js`：隨附的 SheetJS Excel 處理函式庫（0.18.5）；授權條款見 `dist/SHEETJS-LICENSE.txt`。
- `排班需求範例_2026-12.xlsx`、`班表初稿_2026-12.xlsx`：課堂演練用範例檔。
